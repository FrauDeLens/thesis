ABOUT BUGHUNT

✦ PYTHON DEBUGGING & EDUCATIONAL BATTLE PLATFORM ✦

BugHunt is an interactive educational debugging platform engineered to help computing students master Python through practical error diagnosis, traceback analysis, and code repair.

By spotting and fixing categorized bugs across multiple difficulty tiers, players build diagnostic confidence and develop mastery over Depth-First Search (DFS) algorithms.

⚡
Syntax Errors
Grammar traps, missing colons, unclosed quotes, brackets, and block indentation errors.
🧠
Logical Errors
Infinite loops, unmarked visited nodes in DFS, boundary conditions, and off-by-one errors.
💥
Runtime Errors
Execution crashes, ZeroDivisionError, KeyError, IndexError, and Recursion depth limits.
ACADEMIC RESEARCH: Undergraduate Thesis Project
FOCUS AREA: Pedagogical Python Debugging & DFS Algorithms
CORE SYSTEM: BugHunt Interactive Arena Engine
